☁️ Respaldo y migración

La aplicación guarda los datos localmente. Crea un respaldo JSON y guárdalo en Google Drive, OneDrive, iCloud o tu computadora. Así puedes recuperar tus registros al cambiar de teléfono.

📄 Exportación para Excel

Genera un archivo compatible con Excel con las recargas registradas.

🔄 Actualización automática

La V5 utiliza un service worker con actualización de caché. Al publicar una nueva versión, la aplicación comprobará la actualización al abrirse.

📱 Instalar en iPhone

1. Abre esta aplicación desde Safari usando una dirección HTTPS.
2. Toca Compartir ⬆️.
3. Selecciona “Añadir a pantalla de inicio”.
4. Confirma “Añadir”.

Al instalarla, se abrirá como una aplicación independiente.
