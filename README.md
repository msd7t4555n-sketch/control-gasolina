# Control de Gasolina V5

Versión multiplataforma para GitHub Pages, iPhone y Android.

Incluye:
- Verificación con litros requeridos según AVG L/100 km.
- Múltiples vehículos (manteniendo la estructura de V4).
- Control/ranking de gasolineras.
- Reportes mensuales/anuales.
- Exportación compatible con Excel.
- Geolocalización opcional.
- Índice histórico de confiabilidad.
- Respaldo y restauración JSON.
- Actualización del service worker con cambio de caché V5.

Publicación: reemplazar los archivos del repositorio `control-gasolina` por los de este paquete, conservando la misma URL de GitHub Pages.
