CONTROL DE GASOLINA - VERSIÓN 2

Esta carpeta contiene una aplicación web progresiva (PWA).

FUNCIONES:
- Registro de recargas
- Varios vehículos
- Cálculo automático de km/L
- Costo por recarga y costo por km
- Dashboard
- Gráficas
- Alertas de bajo rendimiento
- Historial
- Exportación CSV para Excel
- Respaldo y restauración JSON
- Funcionamiento sin conexión después de instalarse

IMPORTANTE PARA IPHONE:
Safari solo permite instalar una PWA correctamente cuando la aplicación está publicada mediante HTTPS.

Pasos:
1. Publicar estos archivos en un servicio con HTTPS.
2. Abrir la dirección desde Safari en el iPhone.
3. Compartir > Añadir a pantalla de inicio.
4. Abrir desde el icono creado.

Los datos se almacenan localmente en el dispositivo. Usa "Respaldo" periódicamente para conservar una copia.
